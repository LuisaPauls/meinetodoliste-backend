# SpontyBerlin

SpontyBerlin ist eine Webanwendung für spontane Treffen in Berlin.

Nutzer können kleine Treffen zu gemeinsamen Interessen erstellen und daran teilnehmen.
Der Fokus hierbei liegt auf spontanen, unkomplizierten Begegnungen statt auf großen Events.

Ein Meetup enthält zum Beispiel:
-Titel
-Ort
-Kategorie
-Datum 
-Uhrzeit
-maximale Teilnehmerzahl
